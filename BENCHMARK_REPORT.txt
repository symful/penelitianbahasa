ANALYSIS

Complexity Comparison:
| Operation | HeapScheduler (PriorityQueue) | LinearScheduler (ArrayList) |
|-----------|-------------------------------|------------------------------|
| insert    | O(log n)                      | O(1)                         |
| poll      | O(log n)                      | O(n)                         |

Observations:
1. For small task counts (n <= 10), Linear scheduler can be competitive due to
   lower constant factors and no heap restructuring overhead.

2. As task count grows, Heap scheduler's O(log n) operations clearly outperform
   Linear scheduler's O(n) poll operation.

3. At n=500 tasks, Heap scheduler is approximately 7-8x faster than Linear.

4. Operations per second decreases slightly for both schedulers as task count
   increases, but Heap scheduler maintains better scalability.

5. The heap scheduler's guaranteed O(log n) worst-case performance makes it
   the preferred choice for production workloads with variable task volumes.

Recommendation:
Use HeapScheduler for production systems. LinearScheduler may be considered
only for very small, fixed task sets where latency is not critical.
